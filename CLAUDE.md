# ReveillePT — project notes for Claude Code

ReveillePT ("REV-uh-lee P-T") is a personal home physical-therapy app for iPhone and iPad, a brand of AIXE Tech.
It uses the camera to track the body, draws a stick-figure skeleton over the video, measures a joint angle,
fills a goal bar, plays a tone that rises in pitch as you approach the goal, dings at the goal, counts holds and reps,
and saves progress. Testers: Chris Lueking and Irene Lueking (two local profiles on one device).

## Stack (Stage 1: everything on the device)
- Swift 5.9+, SwiftUI, iOS 17+, iPhone and iPad
- AVFoundation camera -> Apple Vision `VNDetectHumanBodyPoseRequest` (2D, 19 joints)
- Pure-Swift engine for angles, smoothing, reps, holds (no UIKit/Vision imports in `Engine/`)
- AVAudioEngine tone + ding, Core Haptics
- SwiftData for local storage (added in step 7)
- Project generated by XcodeGen from `project.yml` (run `xcodegen` after adding files)
- Stage 2: Supabase (Postgres, Sign in with Apple). Stage 3: RevenueCat + StoreKit 2 usage billing.

## Hard rules
- Camera video is NEVER stored or uploaded. Only joint positions, angles, reps and timings are saved.
- Keep `Engine/` platform-independent so it is unit-tested without a camera.
- Not medical advice: every exercise screen keeps a stop-if-it-hurts note.
- Goal angles come from `ReveillePT/Resources/exercises.json`; never hard-code them in views.

## Build plan and gates
Work one step at a time. A step is done only when its test passes on a real device. See `docs/build-plan.md`.
Current status is tracked in `docs/build-plan.md` (Status column).

## Commands
- Generate project: `xcodegen` (install once with `brew install xcodegen`)
- Unit tests: `xcodebuild test -scheme ReveillePT -destination 'platform=iOS Simulator,name=iPhone 16'`
- Device runs: open `ReveillePT.xcodeproj`, pick the iPad or iPhone, Run.

## Folder map
- `ReveillePT/App` app entry and navigation
- `ReveillePT/Camera` capture session
- `ReveillePT/Pose` Vision detection -> `BodyFrame`
- `ReveillePT/Engine` angle math, smoothing, rep counter, exercise models
- `ReveillePT/Feedback` tone, ding, haptics
- `ReveillePT/Recording` joint-trace recording and replay
- `ReveillePT/Views` SwiftUI screens
- `ReveillePTTests` unit tests (engine, recordings)
- `docs/` plan, architecture, goal-angle sources
